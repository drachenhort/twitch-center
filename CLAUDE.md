## What this is

A media-center type solution to view Twitch streams: Twitch login, and viewing the IRC chat
paired to a given streamer. Not designed for communicating back to the streamer — more a second
way to consume streamer-generated content.

(`pytest`, `requests`). There is no build, lint, or test setup to document, and no architecture to
describe, since nothing has been implemented.
